01 — method

Read, plan, act, record.

  1. R

    Read

    Index the procedures you already keep. Contradictions between pages are flagged before a run starts.

  2. P

    Plan

    Each procedure becomes a list of steps with the permissions each one needs. You review the plan once.

  3. A

    Act

    Steps run in your tools with the limits you set. Anything outside them waits for a named approver.

02 — audit

Every step leaves a trace.

03 — questions

FAQ

Can it act without approval?

Only for steps you mark as automatic. Everything else waits for a named approver.

Does it modify source documents?

No. It reads them. Proposed edits go through your normal review.
